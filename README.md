Transport Management System

A web-based Transport Management System that enables users to search and book bus tickets while allowing admins to manage bus details and routes. The project also demonstrates the difference between Monolithic and Microservices Architecture by implementing the booking module as an independent microservice.

Features:

* User login and ticket booking
* Admin panel for bus management
* Booking service implemented as a **REST API microservice**
* JSON-based request/response handling
* MySQL database integration

Architecture:

Monolithic: All modules combined into one PHP application
Microservice: Booking functionality separated and accessed via API

Tech Stack:

HTML, CSS, JavaScript
PHP (Monolithic + Microservice)
MySQL
REST API, JSON
XAMPP (Apache, phpMyAdmin)



Outcome:

Improved scalability and modularity using microservices
Clear comparison of monolithic vs microservice-based systems
